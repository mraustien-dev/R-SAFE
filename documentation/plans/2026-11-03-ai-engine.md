# R-SAFE AI Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor `ai-engine/` into a modular `rsafe` package that detects motorcycles and riders, classifies each rider's helmet, reads plates, and writes integration-ready violation evidence.

**Architecture:** A per-frame pipeline of small units (video source → vehicle detector with tracking → rider association → helmet classifier on head crops → per-track voting → plate reader → evidence writer → sink). Pure logic (association, voting, IDs, JSON) is unit-tested without models; each model sits behind one class configured from YAML.

**Tech Stack:** Python 3.12.10 (`ai-engine/.venv`), Ultralytics 8.4.197 (YOLO11s COCO + ByteTrack), onnxruntime 1.31.1, OpenCV 5.0, PyYAML, pytest, EasyOCR (fallback OCR), requests (HTTP sink).

**Spec:** `documentation/specs/2026-11-03-ai-engine-design.md`

## Global Constraints

- All commands run from `C:\Users\agang\Desktop\R-SAFE\ai-engine` in Windows PowerShell using `.venv\Scripts\python` (never the Python 3.14 root `.venv`).
- `status` in every violation record is `"pending_review"`; the engine never confirms a violation.

- Bounding boxes are `[x1, y1, x2, y2]` pixel floats in the original frame.
- Helmet labels in engine output are exactly `"helmet"` / `"no_helmet"`; plate status exactly `"read"` / `"unreadable"` / `"not_visible"`.

- Back riders (position ≥ 2) are checked and flagged exactly like drivers.
- Logging via `logging.getLogger("rsafe...")`, messages prefixed `[R-SAFE]`; no `print` in `rsafe/`.
- Nothing in `assets/`, `runs/`, `_archive/` is deleted by the engine or by tasks; moves only, and only those listed in Task 1.

## Review Focus

1. **Tracker returns no IDs** (Ultralytics gives `boxes.id is None` on early frames / after loss) → detections without a track ID are skipped for voting, no crash. Test in Task 6.
2. **Boxes touching or crossing the frame edge** → `head_crop` clips to the frame and returns `None` for an empty crop; no OpenCV error. Test in Task 3.
3. **Video ends or user presses Ctrl+C while a no-helmet motorcycle is still in view** → `ViolationTracker.flush()` still emits its violation. Tests in Task 4 and Task 10.
4. **Helmet model finds no box in a head crop** → `classify` returns `None` and no vote is recorded (not counted as helmet). Test in Task 5.
5. **OCR returns lowercase, spaces, dashes or symbols, or an empty string** → normalised to `[A-Z0-9]`; empty after normalisation → `status "unreadable"`. Test in Task 9.

### Task 3: Rider association and head crop

**Files:**
- Create: `rsafe/association/__init__.py`, `rsafe/association/riders.py`

**Interfaces:**
- Consumes: `Detection`, `BBox` (Task 2)
- Produces:
  - `associate_riders(motorcycles: list[Detection], persons: list[Detection], expand_ratio: float, max_riders: int) -> dict[int, list[Detection]]` — key is the index into `motorcycles`; riders ordered front to back (position 1 first).
  - `head_crop(frame: np.ndarray, rider: BBox, head_ratio: float, pad_ratio: float) -> np.ndarray | None`

Rules (spec §5.1–5.2): a person matches a motorcycle when the bottom-centre of the person box lies inside the motorcycle box expanded by `expand_ratio` of its width/height on each side; ties go to the largest intersection area; keep at most `max_riders`, ordering by distance of the person's bottom-centre from the motorcycle's front, approximated as **largest person box height first** (nearest/front rider appears largest), ties by x-centre. Head crop = top `head_ratio` of the rider box, padded by `pad_ratio` of the crop size on all sides, clipped to the frame; return `None` if the clipped crop has zero width or height.

### Task 4: Violation voting rules

**Files:**
- Create: `rsafe/violations/__init__.py`, `rsafe/violations/rules.py`
- Test: `tests/unit/test_rules.py`

**Interfaces:**
- Consumes: `Detection`, `HelmetResult`, `RiderVerdict`, `PlateResult`, `TrackReport` (Task 2); `RulesConfig`, `PlateConfig` (Task 2)
- Produces `class ViolationTracker`:
  - `__init__(self, rules: RulesConfig, max_plate_attempts: int)`
  - `update(self, frame_index: int, frame: np.ndarray, motorcycle: Detection, riders: list[tuple[int, Detection, HelmetResult | None]], now: datetime) -> None` — `motorcycle.track_id` must be an int; tuple is `(position, rider_detection, helmet_result_or_None)`.
  - `wants_plate(self, track_id: int) -> bool` — True while attempts < `max_plate_attempts`.
  - `add_plate(self, track_id: int, result: PlateResult) -> None` — counts an attempt; keeps the best result (`read` beats `unreadable` beats `not_visible`; among `read`, higher `ocr_confidence`).
  - `collect_finished(self, frame_index: int) -> list[TrackReport]` — tracks not updated for more than `track_lost_frames` frames.
  - `flush(self) -> list[TrackReport]` — all remaining tracks.
  - Both return **only** tracks with ≥ 1 rider whose verdict is `no_helmet`, and remove every finished track from memory.

Voting (spec §5.3): per `(track_id, position)` a `deque(maxlen=window)` of `HelmetResult` with `confidence >= min_confidence`; `None` and low-confidence results are not stored. Verdict `no_helmet` iff count(no_helmet) ≥ `min_votes` and count(no_helmet) > count(helmet); `helmet` iff count(helmet) > count(no_helmet); else `unknown`. `RiderVerdict.confidence` = mean confidence of the winning label's votes (0.0 for unknown); `frames_observed` = total stored votes. Best evidence frame = the update where the largest no-helmet-voted rider box area was seen; store a copy of the frame, the motorcycle detection and the rider crop (rider box region of the frame) from that update.

### Task 10: Pipeline and CLI

**Files:**
- Create: `rsafe/pipeline.py`, `scripts/run_pipeline.py`
- Test: `tests/unit/test_pipeline.py`, `tests/smoke/test_run_pipeline.py`

**Interfaces:**
- Consumes: everything above.
- Produces: `class Pipeline.__init__(self, cfg: Config, vehicle, helmet, plate_reader | None, writer: EvidenceWriter, sink: Sink)` (components injected, so tests use fakes); `process_frame(self, frame_index: int, frame: np.ndarray, source: SourceInfo, now: datetime) -> list[Path]`; `finish(self, source: SourceInfo) -> list[Path]`; `annotate(self, frame) -> np.ndarray` (last frame's boxes, track IDs and rider labels, for `--show`). And `build_pipeline(cfg: Config) -> Pipeline`.

`process_frame` order: `vehicle.track` → skip motorcycles with `track_id is None` → `associate_riders` → for each rider with box height ≥ `min_rider_height_px`, `head_crop` → `helmet.classify` → `tracker.update` → if `plate_reader` and `tracker.wants_plate(id)`: `tracker.add_plate(id, plate_reader.read(...))` → `tracker.collect_finished` → write + send each report. Exceptions inside one frame are logged with the frame index and the frame is skipped. `finish` calls `tracker.flush()` and writes those. `models` dict = `{"vehicle": vehicle.name, "helmet": helmet.name, "plate": reader.detector_name or None, "ocr": reader.ocr_name or None}`.

CLI: `.venv\Scripts\python scripts\run_pipeline.py --source <file|url|index> [--config configs/default.yaml] [--show] [--max-frames N]`. Configures `logging` at `cfg.logging.level` with format `[R-SAFE] %(levelname)s %(name)s: %(message)s`. Processes every `frame_stride`-th frame (frame indices stay source indices, so `track_lost_frames` counts source frames); on `KeyboardInterrupt` or end of video calls `finish`; prints a summary (frames processed, average FPS, violations written, output folder). With `--show`, `q` quits (also calls `finish`).
